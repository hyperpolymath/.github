# Support

> Default support guide for all `hyperpolymath` projects. A repository may
> override it with its own `SUPPORT.md`.

Need help? Here's the fastest route to an answer.

## 1. Read the docs

Start with the repository's `README` and any `docs/` directory. Many questions
are answered there.

## 2. Search first

Search existing **Issues** and **Discussions** — your question may already be
answered.

## 3. Ask in the right place

| You want to…                                   | Use                                    |
| ---------------------------------------------- | -------------------------------------- |
| Ask an open-ended question / get help          | **Discussions → Q&A**                  |
| Get a tracked answer to a specific question    | **❓ Question** issue                   |
| Report a bug                                   | **🐛 Bug report** issue                |
| Propose a feature                              | **✨ Feature request** issue           |
| Report a security vulnerability (private)      | See [SECURITY.md](SECURITY.md)         |

## Response expectations

These are primarily research and personal-estate projects maintained by a small
number of people (sometimes one). Best-effort support is offered with no SLA.
Clear, reproducible reports get answered fastest.
